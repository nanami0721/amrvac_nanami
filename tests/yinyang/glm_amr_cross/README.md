# Cross-patch GLM AMR regression

The manufactured states include constant Cartesian vectors and nonuniform
density, pressure, Cartesian velocity, magnetic field and GLM psi. A refinement
request follows an angular seam next to the inner radial wall on Yin. The tests
check three- and four-level layouts, startup refinement, dynamic coarsening, donor migration and
restart from a paired four-level snapshot. Yang uses the interface balance
requests generated by the implementation.

The oracle builds its own leaf coverage map and evaluates the four virtual
donor sites for every tested angular ghost cell. It checks the one-level
stencil bound, the analytic affine state for same-level and coarse-to-fine sites,
and a separate eight-cell conserved volume mean for fine-to-coarse sites.
The uniform and two stretched radial meshes exercise the radial part of the
reconstruction. The special inner condition plants a radial magnetic field in
the ghost layers and checks that the native GLM adjustment removes it at mixed
corners covered by its stencil. The manufactured states are reseeded at regrids
to isolate exchange accuracy.

Build in a case directory outside the source copy. The following commands
assume `AMRVAC_DIR` points to that copy and the case directory contains
`mod_usr.t` and `amrvac.par`.

```sh
"$AMRVAC_DIR/setup.pl" -d=3 -arch=debug
make -j1
python3 "$AMRVAC_DIR/tests/yinyang/glm_amr_cross/run.py" ./amrvac ./cross-results
```

Use `-arch=default` for an optimized run. On macOS provide
`--memory-guard "$AMRVAC_DIR/tests/yinyang/interface_transport/convergence/memory_guard.py"`
to use the project's thresholds. Supply MPI launcher settings with
`--mpiexec`. The runner reports coverage and per-layout errors in
`results.json`. The companion `tests/yinyang/glm_amr` suite checks the two-level interior
case and fixed-grid and native spherical controls.

The sparse index unit test links the actual implementation and exercises
addresses above (2^{31}) at level 20 with three native leaf records. Run it
from the same isolated case directory after the debug archive has been built.

```sh
mpif90 -fcheck=all -I "$AMRVAC_DIR/lib/3d3_debug" \
  "$AMRVAC_DIR/tests/yinyang/glm_amr_cross/sparse_index.f90" \
  "$AMRVAC_DIR/lib/3d3_debug/libamrvac.a" -o sparse_index
./sparse_index
```
